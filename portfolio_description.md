# Portfolio Description

## Project Title

**Ers Shoes: Sales and Inventory Analytics Dashboard**

## Short Description

A PHP and MySQL-based sales and inventory analytics dashboard that helps monitor product performance, transaction data, revenue, stock levels, and restocking priorities for Ers Shoes.

## Long Description

This project was developed as a web-based sales and inventory management system with an added analytics dashboard. The system manages product, customer, staff, transaction, and receipt data through a MySQL database. The analytics dashboard transforms transactional data into business insights, including total revenue, total quantity sold, average transaction value, sales by category, monthly sales trends, top-selling products, and low-stock items.

The project demonstrates data analyst skills through SQL-based data extraction, aggregation, dashboard creation, KPI monitoring, and business insight generation.

## Skills Demonstrated

- SQL data analysis
- MySQL relational database design
- Data aggregation
- KPI dashboard development
- Sales and inventory analysis
- Business insight generation
- PHP web development
- CSV report export
